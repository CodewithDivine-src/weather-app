#Weather App

This is a full-stack weather application bulit with Nexx.js, TypeScript and Tailwind CSS. 
  Users can signup with their name, email, and password , then check current weather and a five(5) day forecast for any city. The dashbord greets the user with a time-based message too( morning/afternoon/evening).  

## Features 
- User authentication (signup/login)with password hasing (bcrypt)
- Live weather data from OpenweatherMap API 
- 5-day forecast 
-Dynamic background based on weather condition 
- personalised greeting ( Good morning/afternoon/ evening)
- Fully responsive design 

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Authentication:** Custom with localStorage + JSON file storage (bcrypt)
- **API:** OpenWeatherMap
